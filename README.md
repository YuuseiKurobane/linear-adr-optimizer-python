# Linear ADR Optimizer Rewrite

This workspace is the standalone rewrite of the ADR parameter simulator.

## Layout

- `Rewrite_adr_pareto/` contains the Python CLI/search wrapper and Plotly web assets.
- `Rewrite_rust/` contains the Rust simulator worker and FSRS/ADR simulation code.
- `Rewrite_helper/` is intentionally not committed/generated by hand. Recreate it from GitHub Actions artifacts when you need packaged helper binaries.

The old helper JSON request/response protocol is intentionally removed. Python starts one long-lived Rust worker, configures it once, and exchanges compact length-prefixed binary frames for evaluation batches.

## Local Build

```powershell
cd C:\Users\admin\Documents\Codex\linear-adr-optimizer\Rewrite_rust
cargo build --release --bin adr-simulator-helper
```

Then run the Python CLI from `Rewrite_adr_pareto`:

```powershell
cd C:\Users\admin\Documents\Codex\linear-adr-optimizer\Rewrite_adr_pareto
python -m adr_pareto --export ..\exports --preset Yuusei
```

Useful output flags:

- `--matplotlib` restores legacy PNG plotting.
- `--recommended-only`, `--aggressive-only`, or `--calm-only` writes one TXT file and prints only that point.
- `--threads 0` uses all available CPU cores; pass a positive number to cap Rust worker threads.

## Recreating `Rewrite_helper`

Push this folder to GitHub with the included workflow. Run the `Build ADR Simulator Helper` workflow, download the four artifacts, extract them, and place the extracted platform folders under `Rewrite_helper/`.
